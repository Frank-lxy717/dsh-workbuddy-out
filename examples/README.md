# 示例产物

`ppt-outline/` 是一次**真实跑通**的结果，不是编的样例：

- 专家：`ppt-implement`（agent `ppt-creation-expert`，自称「幻灯灯」）
- 任务：为「自然语言 CAD 建模」主题做 PPT 大纲
- 产出：`outline.md`（大纲正文）+ `_handoff.md`（交接文档）

值得注意的一点：这位专家写大纲时，主动去读了本机已安装的真实插件源码，大纲里的报错文案和配置键名都是实测过的；交接文档里还专门写了「事实零编造」的自我约束与取舍代价。

看这两个文件能明白这套机制的意图：**产物 + 过程说明**一起回来，主 agent 才能校验和返工，而不是只收到一段没法追问的对话。
